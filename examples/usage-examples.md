# 色母粒海外获客 Skill — 使用示例

以下是几个可直接复制使用的完整提示词示例。

## 示例 1：一键全流程获客（越南）

```
请帮我执行一次完整的色母粒海外获客闭环：
目标市场：越南，产品：定制色母粒 + 阻燃母粒。

1. 市场研究：给出越南市场概况与本地关键词
2. 企业发现：用越南语关键词找 20 家塑料加工企业
3. 线索评分：按适配度打分分级（A/B/C）
4. 开发信：为评分最高的 5 家各写一封越南语开发信草稿
5. 汇总：把结果整理成本地 CSV 线索表

注意：开发信仅草稿不发送；所有信息标注来源，不编造。
```

## 示例 2：调研土耳其市场

```
请用市场研究 Agent 视角，调研土耳其市场，目标产品：定制色母粒、阻燃母粒。
输出：市场规模、主要下游行业、产业集群城市、土耳其语获客关键词 20 个、进入建议与风险。
```

## 示例 3：深挖某家企业官网

```
请用官网研究 Agent 视角，分析这家企业官网：https://example.com
1. 主营业务与产品线
2. 是否使用需要配色/改性的塑料
3. 可联系的人或部门线索
4. 他们是否需要定制色母粒 / 阻燃母粒？理由？
只提取公开信息，标注来源，不编造。
```

## 示例 4：批量评分线索

```
请对下面 20 家企业线索批量评分分级（A/B/C），
输出表格：company_name, 产品匹配, 需求强度, 规模, 触达性, 地域, 总分, 等级, 理由。
按等级排序，A 级排最前。
```

## 示例 5：写土耳其语开发信

```
请用商务沟通 Agent 视角，给这家土耳其企业写一封土耳其语开发信草稿：
- 公司名：xxx
- 业务：注塑 / 挤出
- 我们优势：定制色母粒 + 配色打样 + 阻燃母粒
生成草稿（不发送），语气专业、克制、不夸大。
```

## 示例 6：谷歌地图抓取客户（`tools/maps_scrape.py`）

```
cd D:\masterbatch-leadgen
python tools/maps_scrape.py "Ohio" "injection molding Cleveland,plastic extrusion Columbus,blow molding Cincinnati"

（脚本输出 leads/<日期>-map-Ohio.json，每家含 name/tel/addr）
```

拿到 JSON 后，让 AI 整理：

```
以下是 tools/maps_scrape.py 抓取的【美国俄亥俄州】塑料加工企业数据：
【粘贴 JSON】

请用地图抓取 Agent 视角：
1. 去重，过滤掉非塑料加工类企业（回收/设备/贸易商）
2. 按行业（注塑/挤出/吹塑/包装）分类
3. 提取每家：公司名、地址、电话
4. 标注哪些可能需要定制色母粒 / 阻燃母粒
5. 输出成结构化表格，来源标注「Google Maps」
```

## 示例 7：多渠道触达文案（邮件 + WhatsApp + LinkedIn）

```
请用商务沟通 Agent 视角，为这家越南注塑厂生成三种触达文案（越南语）：
- 公司名：xxx，业务：注塑，公开邮箱：xxx@xxx

1. 邮件：主题行 + 正文 + 签名（专业）
2. WhatsApp 开场白：2-3 句（口语化、友好）
3. LinkedIn 连接请求 + 首条私信（50 字内）

要求：三份内容风格适配各自渠道；只生成可复制的文案，不自动发送。
```

## 示例 8：发送前合规审核

```
请用总经理 Agent 视角，对以下即将发送的开发信做合规审核：
【粘贴开发信】

检查项：
1. 是否虚构资质/认证/数据？  2. 是否夸大？
3. 是否提及第三方客户信息？  4. 公司名/产品是否写对？
5. 语气是否专业克制？        6. 来源是否可追溯？

输出：逐条检查结果 + 修改后的最终版（标记「已审核，可人工发送」）。
```
