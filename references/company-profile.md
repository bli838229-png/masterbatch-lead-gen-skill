## 三、实力点 → 落位规则（怎么用、用在哪）

**原则：不用全部写，按「哪句话能打消客户顾虑」挑 2-3 个最相关的点，放对位置。**

| 位置 | 优先用哪个点 | 为什么 |
|---|---|---|
| **开场白（Zalo/WhatsApp 第一句）** | 20+ 年历史 + 年产能 + SGS 认证 | 陌生客户只看 3 秒，先甩硬实力建立可信度 |
| **开发信第 1 段（我是谁）** | 成立年份 + 厂房面积/设备 + 工厂非贸易商 | 一句话说清"老牌工厂"身份 |
| **开发信第 3 段（差异化背书）** | ISO9001 + SGS + 技术团队 | 回应质量/合规/技术支持疑虑 |
| **结尾钩子** | 免费配色打样 + 寄样 | 促成交（结合分行业痛点） |

**注意**：
- 认证（ISO9001 / SGS）必须真实，不得虚构或夸大等级、范围。
- 欧美客户重合规与数据，德国等市场重点强调 ISO9001 + SGS + 环保合规而非营业额。
- 食品/医药/家电等行业客户，务必提「SGS 检测认证 + 符合各国环保要求」。

## 五、签名模板（邮件结尾统一用）

> 签名里的姓名/公司/邮箱/WhatsApp 会自动从 `tools/profile.json` 读取（见 `tools/outreach_copy.py`）。
> 只需在 `tools/profile.json` 里填一次，所有开发信/开场白的签名都会带上你的真实信息。

```
[开发信正文]

Trân trọng / Saygılarımla / Best regards / Saludos cordiales,
{你的英文名}
{你的公司英文全称}
Email: {你的邮箱} | WhatsApp: {你的 WhatsApp}
```

> **真实联系方式（写签名必用，禁止用占位符发给客户）**：
> - 邮箱：在 `tools/profile.json` 的 `email` 字段填写你的真实邮箱
> - WhatsApp：在 `tools/profile.json` 的 `whatsapp` 字段填写（越南 Zalo 也常用同一号码）
