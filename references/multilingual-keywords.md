# 多语言获客关键词库（精准搜索版）

使用目标国家的**本地语言**搜索，命中率远高于英文。本文档在基础关键词之上，增加**高级搜索语法、决策人职位词、采购信号词**，让你搜到的不是"公司列表"，而是"能直接联系的人"。

---

## 一、Google 高级搜索语法（抓取效果翻倍的关键）

组合这些运算符，能精准命中"官网联系页、采购负责人、B2B 名录页"：

| 语法 | 作用 | 示例 |
|---|---|---|
| `"关键词"` | 精确匹配短语 | `"plastic injection molding"` |
| `intitle:` | 标题含某词 | `intitle:"contact" "plastic"` |
| `inurl:` | 网址含某词 | `inurl:contact "injection molding"` |
| `site:` | 限定某域名 | `site:linkedin.com "procurement" "plastic"` |
| `filetype:` | 限定文件类型 | `filetype:pdf "company profile" "plastic"` |
| `-`（减号） | 排除某词 | `"plastic" -"recycling"`（排除回收商） |
| `OR` | 或 | `"injection" OR "extrusion"` |
| `..`（数字范围） | 范围 | `"plastic" "employees" 50..500` |

### 高效组合模板（直接套用）

**找"联系页/邮箱页"：**
```
[本地语言"注塑"] inurl:contact
[本地语言"塑料"] inurl:lien-he  (越南语"联系")
```

**找"采购/供应链决策人"（LinkedIn 辅助，手动操作）：**
```
site:linkedin.com [国家] "procurement" OR "purchasing" "plastic"
site:linkedin.com [国家] "sourcing manager" "packaging" OR "injection"
```

**找"公司简介 PDF"（含电话/邮箱）：**
```
filetype:pdf [本地语言"塑料"] "company profile"
filetype:pdf "catalog" "masterbatch" "color"
```

**找"展会参展商名录"：**
```
[国家] plastic exhibition exhibitor list 2025
[本地语言"塑料展"] "danh sách nhà triển lãm"  (越南语)
```

### 缺失语种怎么补（扩展规则）

矩阵里没有的语言（泰语 / 波兰语 / 阿拉伯语 / 荷兰语 / 马来语 / 越南语外的东南亚语等），按这 3 步生成，**不要凭感觉编**：

1. **取核心词**：先确定该国「色母粒」和「注塑/挤出」的行业通用词 —— 查该国塑料工业协会官网、或该国维基百科的 `masterbatch` 词条（多数语言有对应词）。
2. **补英文兜底**：**很多非英语国家的企业官网同时挂英文版**，所以 `英文关键词 + site:.国别域名`（如 `"injection molding" site:.th`）往往比当地语言更有效，务必并列搜一轮。
3. **回写本文件**：新语种关键词补成同样格式的表格，并回写 `outreach-templates.md` 的触达矩阵。**每跑一个新市场，库就厚一层。**

## 五、社交媒体深挖关键词（Facebook + LinkedIn）

> 社交号（Zalo/WhatsApp/KakaoTalk）和采购决策人，是色母粒外贸触达的"最后一公里"。Facebook 和 LinkedIn 的搜索规则完全不同，务必分开用对关键词，否则搜到一堆同名噪声或直接撞登录墙。

### 5.1 Facebook 搜索（找企业官方主页 → 挖社交号）

**核心认知**：越南/东南亚中小塑料厂的 Facebook 主页名多为**本地语言**（如 "Công ty Nhựa XXX"、"Nhựa Tân Tiến"），英文公司名常常搜不到，或被同名实体（景点、宠物节、其他行业）污染。

**三条搜索路径（按命中率排序）**：

| 优先级 | 路径 | 关键词 / 语法 | 说明 |
|---|---|---|---|
| ⭐⭐⭐ | **从官网抓 FB 链接**（最可靠） | 直接解析官网 `<a href>` 里的 `facebook.com/xxx` | 越南企业官网 footer/联系页几乎都挂 FB 图标，命中率最高，且是**官方主页、零噪声** |
| ⭐⭐ | **Google 定位官方主页** | `site:facebook.com "公司本地语言名"`<br>`site:facebook.com "公司名" plastic` | 用 `site:` 语法让 Google 替你搜 Facebook，比 FB 站内搜索抗噪 |
| ⭐ | **Facebook 站内搜索** | 主页名 = 本地语言公司全称 | 需登录态；同名噪声多，只在前两条都失败时兜底 |

**Facebook 主页深挖关键词（进入主页后抓什么）**：
- 社交号：`zalo` / `Zalo` / `zalo.me/` / `whatsapp` / `wa.me/` / `Hotline`（越南主页简介和置顶帖里最常挂 Zalo/WhatsApp）
- 联系方式：`Điện thoại`（电话）/ `Email` / `info@` / `sales@`
- 判断真伪：核对主页简介里的**产品线**（HDPE 波纹管、注塑件等）是否匹配，排除同名无关主页

### 5.2 LinkedIn 搜索（找公司页 + 采购决策人）

> 🔴 **铁律**：LinkedIn **只手动、不自动化**搜人和加好友（自动化会永久封号）。AI 只负责「告诉你该搜谁、用什么关键词搜、搜到后怎么开场」。

**找公司页（无需登录，Google 就能搜）**：

| 用途 | 关键词 / 语法 |
|---|---|
| 定位公司官方页 | `site:linkedin.com/company/ "公司名"` |
| 带行业限定 | `site:linkedin.com/company/ "公司名" plastic` |
| 带国家限定 | `site:linkedin.com/company/ "公司名" "Vietnam"` |

**找采购/供应链决策人（核心价值，需登录 LinkedIn）**：

| 目标岗位 | 英文职位词（LinkedIn 用英文最准） | 补充词 |
|---|---|---|
| 采购 | `Purchasing Manager` / `Procurement` / `Buyer` / `Sourcing Manager` | `Category Manager` |
| 供应链 | `Supply Chain Manager` / `Supply Chain Director` | `Materials Manager` |
| 技术/研发 | `R&D Manager` / `Materials Engineer` / `Product Development` | `Technical Manager` |
| 管理层 | `General Manager` / `Managing Director` / `Founder` / `Owner` | `Plant Manager` |

**LinkedIn 站内搜索组合公式**（在 LinkedIn 搜索框里用）：
```
"公司名" "procurement"          # 锁定该公司的采购岗
"公司名" "supply chain"         # 供应链岗
"公司名" "general manager"      # 一把手（越南中小厂常一人多职）
```
> 进阶：公司页的 **「People」标签**里直接按部门筛「Operations / Purchasing / Supply Chain」，比全局搜索更精准、更少被 commercial use limit 卡住。

**欧美市场特别注意**：欧美决策人主力在 LinkedIn，触达优先用 LinkedIn + WhatsApp（不是 Zalo）。搜到决策人后，用「职位词 + 公司名」交叉核验，再写 personalized connection request（见 `outreach-templates.md`）。
