# 获客闭环工作流（务实版 · 稳且不封号）

本文档拆解「市场研究 → 谷歌地图抓取 → 企业发现 → 官网深挖 → 邮箱挖掘 → 线索评分 → 开发信草稿 → 多渠道触达（邮件 / WhatsApp / LinkedIn）→ 人工发送 → 整理与审核」的完整获客闭环。

> **核心理念（务必先读）**：
> 本 Skill 采用「**AI 备料 + 人点发送**」的务实自动化策略。AI 负责所有**抓取、筛选、写作、整理、审核**的"重活"，但**对外发送动作（邮件/WhatsApp/LinkedIn）一律由人工手动完成**。这样既高效，又不会因违反平台规则导致账号被封。**账号是你的命根子，客户关系是无价的。**

## 浏览器自动化接入（browser-use）· 何时用浏览器、何时用搜索

> 🔴 **现行方案以 [`browser-deep-dive.md`](browser-deep-dive.md) 为唯一准绳**。本章只讲"什么时候该用浏览器"，具体命令、端口、降级规则一律看 browser-deep-dive.md，不要在本文件里自创方案。

**核心原则**：能用简单 HTTP 抓取/联网搜索解决的，不用浏览器；需要「JS 渲染 + 交互操作 + 反爬页面」时才上浏览器。

**主通道（唯一正确姿势）**：用**用户自己本机正在运行的 Chrome**，通过 `BU_NAME=mainchk browser-use` 自动发现，**不设 `BU_CDP_URL`、不用 9222/9223 固定端口、不自建 headless**。用户 Chrome 走系统代理，Google 搜索/地图才通（实测：自建 Chrome 带 `--no-proxy-server` 会导致 Google 全域 `ERR_CONNECTION_TIMED_OUT`）。首次连接需用户在 Chrome 弹窗点一次 **Allow**。

### 浏览器 vs 搜索的选择标准

| 场景 | 用什么 | 理由 |
|---|---|---|
| 公开页面的文本信息（新闻、目录列表、简介） | 🔍 **联网搜索 / WebFetch** | 轻量、快、不占浏览器 |
| 批量抓本地实体企业（名称/电话/地址） | 🌐 **浏览器 + `tools/maps_scrape.py`** | 谷歌地图真实结果，多关键词分片抓取 |
| 企业官网「联系页」挖邮箱/电话/决策人 | 🌐 **浏览器 + `tools/site_deepdive.py`** | 很多官网 JS 渲染、需滚动/点子页 |
| 反爬/验证码/需要真实点击的页面 | 🌐 **浏览器** | 真实渲染 + 交互 |
| 一次性项目 / 大量公开数据 | 🔍 **搜索** | 浏览器逐页点效率低 |

### 浏览器深挖的提示词模板

```
请用浏览器（browser-use，主通道=用户自己的 Chrome）打开这家企业官网【URL】并深挖联系方式：
1. 打开首页 + /contact、/about、/lien-he（当地语言联系页）
2. 提取：所有公开邮箱、电话、地址
3. 提取采购/销售/总经理等决策人姓名与职位
4. 判断是否有社交通信号（按市场切换：越南→Zalo、韩国→KakaoTalk、日本→LINE、泰国→LINE、欧美→WhatsApp/LinkedIn、中东·拉美→WhatsApp；该市场不用的渠道如实标注，不编号码）
5. 标注来源页面 URL，找不到的写「未找到公开邮箱」，不猜测拼接
只提取公开可见信息，不编造。
```

> **具体命令、端口探测、品牌匹配防错配、降级兜底** 见 [`browser-deep-dive.md`](browser-deep-dive.md)。

## 第 2 步 · 谷歌地图抓取客户（客户开发 Agent + 浏览器脚本）

**目标**：按国家/地区批量抓取塑料加工企业的公开信息（名称 / 电话 / 地址）。

**现行唯一方案：`tools/maps_scrape.py`（浏览器抓谷歌地图真实结果）**

> 🔴 **不要再用 Google Places API**——本机没有 API Key，历史上一直空转；也**不要自建 headless 浏览器**。改用真实 Chrome 无人值守抓地图结果，多关键词分片替代滚动（Maps feed 是虚拟列表、滚动不灵）。

```bash
cd D:\masterbatch-leadgen
python tools/maps_scrape.py "Ohio" "injection molding Cleveland,plastic extrusion Columbus,blow molding Cincinnati,custom compound Toledo"
```

- **参数**：`地区` + 逗号分隔的 4-6 组关键词（**每组含城市名**，结果差异更大）。
- **输出**：`leads/<日期>-map-<地区>.json`（name / tel / addr / src_query）。
- **原理**：每个查询抓 10-20 家，合并去重凑满 30+。
- **实测**：6 组关键词单会话批量执行约 100 秒，抓到 42 家（超过 30 家铁律）。

> ⚠️ 地图列表页**不给官网链接**（"网站"是 JS 按钮），官网必须靠第 4 步 `site_deepdive.py` 补。
> ⚠️ 地图跑不起来（Chrome 未连接/未授权）才降级 WebSearch，并在日志写清降级原因。

**关键词分层**（按 A/B/C 层级选词，详见 [`tiered-keywords.md`](tiered-keywords.md)）：
- A 级：`engineering plastic injection molding` / `UL94 flame retardant molding` / `automotive plastic parts`
- B 级：`injection molding` / `plastic extrusion` / `blow molding` / `plastic packaging`
- C 级排雷：结果里剔掉 `plastic recycling`、`machine shop`、纯贸易商

## 第 2.5 步 · 海关数据搜买家（客户开发 Agent + 浏览器脚本）

**目标**：通过海关进出口数据，找到**正在实际进口色母粒 / 母粒的下游买家**——采购意向最真实的高质量线索。

> 完整方法、产品词库、核验流程、4 个免费资源对比，见 [`customs-data.md`](customs-data.md)。本节只给「该做什么」。

**主通道：ImportYeti（美国海运提单，免费免注册）**

```bash
cd D:\masterbatch-leadgen
# 按产品词搜美国进口商（走你自己的 Chrome，首次需点 Allow）
python tools/customs_scrape.py "color masterbatch,colorant,color concentrate,masterbatch"
```

- **输出**：`leads/<日期>-customs-<词>.json`（进口商名称 + 柜量线索）
- **三条搜索路径**：① 产品词盲捞新客户（首选）；② 竞品供应商反查「谁在买中国色母粒」；③ 已有名单验证采购真实性。
- **抓到后必须核验**：官网确认产品匹配 → LinkedIn 找采购 → 补邮箱 → 排除货代/贸易中间商。
- ⚠️ 开发信**不要提海关数据**（提单/供应商/数量），只说「注意到贵司有 XX 产品线」，避免让客户觉得被监视。
- ⚠️ 仅覆盖美国海运；其他国家用 Volza 样本 / UN Comtrade 统计兜底（无具体公司名，只定方向）。

**与地图/搜索的关系**：三个来源互补去重。地图/搜索找「生产的」，海关数据找「在进口的」，入库按四键去重合并。

**目标**：从联网搜索发现海外潜在客户（地图抓取之外的补充渠道）。

**搜索策略**：
- 用**目标国家本地语言**关键词搜索（见 `multilingual-keywords.md`）。
- 搜索渠道：企业官网、B2B 目录（越南 yellowpages、土耳其 Kompass 等）、行业展会参展商名录。
- 优先找「塑料加工厂」而非「色母粒同行」——他们才是你的**客户**。

**提示词模板**：

```
请用客户开发 Agent 视角，帮我找【国家】的塑料加工企业，
这些企业可能需要【定制色母粒 / 阻燃母粒】。
搜索要求：
1. 使用【当地语言】关键词
2. 列出【20】家候选企业
3. 每家标注：公司名、官网、所在城市、主营业务
4. 来源必须真实，找不到官网的标注「待核实」
```

## 第 4 步 · 官网深挖（官网研究 Agent）

**目标**：对重点企业提取官网公开信息，判断真实需求与联系人线索。

> **优先用浏览器（browser-use）**：官网的联系页/页脚邮箱/决策人信息常需 JS 渲染或点子页，用浏览器直连本机 Chrome 深挖，比纯搜索更完整。静态公开信息仍可用 WebFetch/搜索兜底。详见上文「浏览器自动化接入」章节。

**要提取的信息**：
- 主营业务与产品（是否注塑/挤出/线缆/建材）
- 使用材料（是否 PP/PE/ABS/PC/PA 等可配色的树脂）
- 联系方式线索（联系邮箱、采购/技术负责人线索）
- 公司规模与市场（出口导向？）

**提示词模板**：

```
请用官网研究 Agent 视角，分析这家企业的官网【URL】：
1. 主营业务与产品线
2. 是否使用需要配色/改性的塑料
3. 可联系的人或部门线索（采购/技术/总经理）
4. 你认为他们是否需要定制色母粒 / 阻燃母粒？理由？
只提取公开可见信息，标注来源，不编造。
```

**合规方式（按优先级）**：

## 第 8 步 · 多渠道触达（半自动：AI 备料 + 人点发送）

这是本 Skill 的**核心原则落地处**。针对三种渠道，AI 分别备好"可直接复制粘贴的内容"，由你手动发送。

### 8.1 邮件（Gmail）

- **AI 做**：生成个性化多语言邮件草稿 + 主题行 + 发送建议时间。
- **你做**：登录 Gmail，复制草稿，手动点发送。
- **控速建议**：每天发送 20-30 封，避免批量群发触发 spam。用真实签名、避免雷同内容。

**提示词模板**：

```
请用商务沟通 Agent 视角，为以下企业各生成一封【越南语】开发信，
并给出主题行、正文、签名：
企业清单：【粘贴企业名 + 业务 + 邮箱】

要求：
1. 每封个性化，提及对方公司名和业务
2. 语气专业、克制、不夸大
3. 每封结尾一个明确请求（能否聊聊 / 能否发色板）
4. 标注这是「草稿，需人工发送」
```

### 8.2 WhatsApp

- **AI 做**：生成简短的 WhatsApp 开场白（比邮件更短、更口语化），并整理出"哪些号码是 WhatsApp 号"。
- **你做**：手动在 WhatsApp 里搜索号码 → 添加 → 发送开场白。
- ⚠️ **不批量自动加好友/群发**（非官方自动化会被 Meta 封号）。

**开场白提示词模板**：

```
请用商务沟通 Agent 视角，为以下客户生成 WhatsApp 开场白（【越南语】）：
客户：xxx（注塑厂）
要求：2-3 句，口语化、友好、不推销味太重，点明「我们是色母粒工厂」，
结尾一个轻松的问题（如「你们目前用哪家色母粒？」）。
```

### 8.3 LinkedIn（仅辅助，不自动化）

- **AI 做**：告诉你「该联系谁（采购/Purchasing、供应链/Supply Chain、总经理）、为什么、开场白怎么写、加好友请求怎么写」。
- **你做**：手动在 LinkedIn 搜索、发送连接请求、私信。
- 🔴 **绝不用自动化工具抓取/群发 LinkedIn**，否则账号永久封禁。

**提示词模板**：

```
请用官网研究 Agent + 商务沟通 Agent 视角，帮我制定 LinkedIn 触达策略：
目标公司：xxx
1. 该联系公司里的什么职位（采购经理？供应链？总经理？）
2. 连接请求（connection request）怎么写（50 字内）
3. 通过后的第一封私信开场白怎么写
4. 不要自动发送，只给我可复制的内容。
```

## 第 9 步 · 整理与审核（总经理 Agent）

**目标**：把所有数据整理成可追踪的表格，并做合规审核。

### 9.1 整理成线索池

**CSV 字段（与 `master-lead-pool.csv` 实际表头严格一致，共 21 列）**：

| 列序号 | 字段（中文表头） | 说明 |
|---|---|---|
| 1 | 排名 | 当日按总分降序的名次 |
| 2 | 国家 | 目标市场国家 |
| 3 | 公司名 | 真实公司名 |
| 4 | 行业 | 下游行业（注塑/挤出/线缆/包装…） |
| 5 | 城市 | 所在城市 |
| 6 | 总分 | 7 维之和（0-35），必须是**纯数字**，否则判为字段错位 |
| 7 | 等级 | A / B / C（不得是其他值） |
| 8 | 官网 | 客户**自有**官网 URL（禁止填 thomasnet/contactout/growjo/rocketreach 等目录站） |
| 9 | 邮箱 | 公开邮箱 |
| 10 | 电话 | 公司电话 |
| 11 | 联系人 | **只写姓名**（如 `Steven Ames`），无则「待核实」 |
| 12 | 职位 | 与联系人分开存（如 `Director of Sales`），历史行混写的标「待拆分」 |
| 13 | WhatsApp | 三态标注：明确绑定✅ / 待验证⚠️ / 明确无—；该市场不用则「该市场不使用—」 |
| 14 | Zalo | 同上（美国等不用 Zalo 的市场填「该市场不使用—」） |
| 15 | LINE | 日本 / 泰国主渠道；其他市场填「该市场不使用—」 |
| 16 | KakaoTalk | 韩国主渠道；其他市场填「该市场不使用—」 |
| 17 | 官网产品 | ⭐ 从产品页抄下的 2-5 个具体产品名 + 树脂，**开发信锚点的唯一来源**；拿不到填 `⚠️未获取（原因）` |
| 18 | 跟进状态 | 未联系 / 已发信 / 已回复 / 已报价 / 已寄样 / 成交 / 无效 —— **决定市场能否切换** |
| 19 | 最后联系日 | YYYY-MM-DD，未联系留空 |
| 20 | 切入建议 | 一句话痛点→产品匹配 |
| 21 | 来源 | 信息来源 URL |

> 🔴 **入库前必须跑校验器**：`python tools/schema_check.py [文件]`。它拦截：表头/列序不符、列数不一致（未转义逗号）、总分非数字、等级非法、跟进状态非法、7 维之和≠总分、**官网为目录站/数据商**、公司名或域名重复。
> 历史教训：曾有 1 行因「行业」含未转义逗号整行右移（`总分` 变成城市名）；曾有 14 行「官网」被填成 thomasnet/growjo 等数据商页面（其中 7 家是 A 级），导致官网产品永远抓不到。

### 9.2 自动审核（发送前检查清单）

发送任何消息前，AI 先跑一遍审核清单：

**审核提示词模板**：

```
请用总经理 Agent 视角，对以下即将发送的开发信做合规审核：
【粘贴开发信】

检查项：
1. 是否虚构资质/认证/数据？→ 必须删改
2. 是否夸大（全球第一/最好）？→ 必须删改
3. 是否提及第三方客户信息？→ 必须删除
4. 公司名、产品是否写对？→ 核对
5. 语气是否专业克制？→ 调整
6. 来源是否可追溯？→ 补标注

输出：逐条检查结果 + 修改后的最终版（标记「已审核，可人工发送」）。
```

## 完整闭环提示词（一键全流程 · 务实版）

