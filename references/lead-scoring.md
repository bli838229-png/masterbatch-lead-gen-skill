# 线索评分标准（专业版）

对每一条线索打分分级，把有限的精力聚焦在**高价值、可成交**的客户上。评分不是目的，**决定"先联系谁、花多少力气"才是目的**。

---

## 一、评分维度（7 维 + 负分项）

每项 0-5 分，总分基础分 35 分；另有**负分项**（一票否决 / 扣分）。

### 核心维度（每项 0-5 分）

| # | 维度 | 评估问题 | 高分信号（4-5 分） | 低分信号（0-1 分） |
|---|---|---|---|---|
| 1 | **产品匹配度** | 他是不是"需要定制色母粒/阻燃母粒"的人？ | 明确做注塑/挤出/线缆/建材/家电/汽车内饰，使用 PP/PE/ABS/PC/PA/POM 等可配色树脂 | 做纯贸易、或只用原生色料、或与你产品无关 |
| 2 | **需求强度** | 有没有"现在就要"的迹象？ | 有扩产新闻、在招配色/采购岗、发布新品、参展 | 无任何动态、多年未更新 |
| 3 | **规模匹配度** | 体量是否落在你的产能甜蜜区？ | 中等规模（既非作坊也非巨头），订单量匹配你的产线 | 家庭作坊（单太小）或超级巨头（门槛高、账期长） |
| 4 | **决策人可触达性** | 能否直接找到"说了算的人"？ | 官网有采购经理/供应链/总经理的姓名+邮箱/电话 | 只有 info@，无任何人名 |
| 5 | **联系渠道质量** | 联系方式是否真实、直接？ | 公开的 sales@/采购专属邮箱 + WhatsApp/Zalo + 有联系人姓名 | 邮箱需猜测、号码疑似失效 |
| 6 | **地域适配** | 是否在目标市场与物流半径内？ | 目标国家、靠近港口/物流枢纽、出口导向 | 偏远内陆、物流成本高 |
| 7 | **采购周期/频率** | 是不是会"持续复购"的客户？ | 连续生产型工厂（需长期稳定供色母粒），非一次性项目 | 一次性工程、打样即止 |

> **设计逻辑**：外贸成交 = 匹配 × 需求 × 触达 × 关系。第 1-3 项决定"值不值得做"，第 4-5 项决定"够不够得着"，第 6-7 项决定"能不能长期做"。

### 负分项（重要）

| 负分项 | 处理 |
|---|---|
| **已明确不采购 / 已有长期独家供应商** | 直接降为 C 级（一票否决），除非有"切换供应商"信号 |
| **信息为编造/无法核实来源** | 整条线索作废，不得进入线索池 |
| **规模严重错配**（例如你要做 20 吨/月的定制单，对方是万吨级只认大厂） | 扣 3 分 |
| **物流/关税严重不利**（如对方在非目标地区且关税壁垒高） | 扣 2 分 |

## 二、行业加权规则（色母粒专属）

不同下游行业，对"定制色母粒/阻燃母粒"的**价值密度**不同。在"产品匹配度"这一项里，可按行业加权：

| 下游行业 | 加权倾向 | 原因 |
|---|---|---|
| **工程塑料注塑**（POM/PA6/PA66/PC/ABS） | ⬆️ 加分 | 着色门槛高、单价高、客户粘性强 |
| **家电/电子外壳**（需阻燃 UL94 V0） | ⬆️ 加分 | 阻燃母粒是刚需，认证壁垒高 |
| **汽车内饰/外饰** | ⬆️ 加分 | 配色要求高、长期稳定订单 |
| **医药/食品包装** | ⬆️ 加分 | 需食品级/医药级认证，客户忠诚度高 |
| **线缆料/电缆** | ➖ 中性偏上 | 用量大但竞争激烈，看价格 |
| **通用塑料日用品**（脸盆、衣架） | ➖ 中性 | 用量大但价格敏感、粘性低 |
| **一次性项目/工程件** | ⬇️ 减分 | 无复购 |

## 三、分级标准（35 分满分）

| 等级 | 总分 | 含义 | 标准动作 |
|---|---|---|---|
| **A** | ≥ 28 | 高价值、高匹配、可触达 | 定制化开发信 + 官网深挖 + 加 WhatsApp/Zalo + 每周跟进 |
| **B** | 18-27 | 有潜力，需补信息确认 | 批量开发信 + 补齐联系方式 + 2 周后跟进 |
| **C** | < 18 | 低匹配 / 信息不足 / 有负分 | 暂缓或补充调研，不主动投入精力 |

> **A 级建议控制在 10%-20%**。如果 A 级占比过高，说明你的评分太松，需要提高门槛；占比过低则说明线索源质量差，需换关键词或数据源。

## 四、评分提示词模板

### 单条精评

```
请用客户评估 Agent 视角，对以下企业线索打分：

【企业信息】
- 公司名：xxx
- 主营业务：xxx
- 使用材料（树脂）：xxx
- 官网：xxx
- 公开联系方式：xxx
- 国家/城市：xxx
- 动态信号（扩产/招聘/新品）：xxx

请按以下 7 维打分（每项 0-5 分）：
1. 产品匹配度  2. 需求强度  3. 规模匹配度  4. 决策人可触达性
5. 联系渠道质量  6. 地域适配  7. 采购周期/频率

再判断有无负分项（已不采购 / 信息不可核实 / 规模错配等）。

输出格式：
- 各项得分 + 总分（/35）+ 等级（A/B/C）
- 一票否决或扣分项（如有）
- 评分理由（一句话）
- 建议动作（深挖 / 批量开发 / 暂缓）

原则：只依据已提供信息打分；信息不足的维度标「信息不足」并给 0 分，绝不臆测编造。
```

### 批量评分

```
请对下面【N】家企业线索批量评分分级。
【粘贴线索列表，含：公司名、业务、材料、官网、联系方式、国家、动态信号】

按 7 维打分（产品匹配/需求强度/规模匹配/决策人触达/渠道质量/地域适配/采购周期），
输出一张表格，列：排名, company_name, 匹配, 需求, 规模, 触达, 渠道, 地域, 周期, 总分, 等级, 负分项, 建议动作。
按总分从高到低排序（同分并列，A 级排最前）。

【重要】除了表格，还要为每家输出「评分理由」：
- 每个维度的得分后面，跟一句理由（指向具体证据）
- 信息不足的维度标「信息不足」给 0 分，绝不臆测
- 最终汇总成一条"总分 + 等级 + 一句话总评"

输出既要能生成表格，也要能生成逐维明细看板（A/B/C 全量、排名、分数条、逐维理由）。
```

## 四·五、评分透明化（每一条都要"可解释、可追溯"）

> **核心原则：评分不是黑箱。** 给任何客户一个 A/B/C 等级之前，必须能回答三个问题：**他排第几？总分多少？凭什么给这个分？** 缺一不可。

### 每条线索必须输出的「评分明细」结构

评分结果不能只给一个字母，必须附带完整明细：

```text
【评分明细 · 必填字段】
- 排名：第 N 名 / 共 M 家（按总分降序，同分并列）
- 总分：xx / 35
- 等级：A / B / C
- 各维度得分（7 项，每项 0-5）：
  ① 产品匹配度：x 分 —— 理由：…
  ② 需求强度：x 分 —— 理由：…
  ③ 规模匹配度：x 分 —— 理由：…
  ④ 决策人可触达性：x 分 —— 理由：…
  ⑤ 联系渠道质量：x 分 —— 理由：…
  ⑥ 地域适配：x 分 —— 理由：…
  ⑦ 采购周期/频率：x 分 —— 理由：…
- 负分项：无 / 扣 x 分（原因）
- 一票否决：无 / 已触发（原因）
- 一句话总评：…
```

### 评分理由的写法规范

| 要求 | 说明 | 反例 |
|---|---|---|
| **每个维度必须有理由** | 不能只写数字 | ❌ "需求强度：4分" |
| **理由要指向具体证据** | 引用官网/数据里的事实 | ❌ "感觉挺有需求" ✅ "官网有招聘配色工程师 + 扩产新闻" |
| **信息不足要明说** | 缺数据就给 0 分并标注"信息不足"，绝不臆测 | ❌ 凭空猜一个分 |
| **理由可复现** | 别人看了理由，能倒推出这个分 | ❌ "综合看还不错" |

### 看板/清单输出要求

生成客户清单或 HTML 看板时，**必须包含 A/B/C 全部客户**（不是只放 A 级），并按以下结构展示：

1. **全量排名**：所有客户按总分从高到低排，显示「第 N 名」徽标。
2. **分数条可视化**：每个客户用 7 根小分数条（0-5 分），一眼看清强弱项。
3. **逐维理由**：每个维度下挂一句理由，点击/展开可见。
4. **等级筛选**：支持按 A / B / C 一键筛选，方便分批处理。

## 五、评分后必做的动作（把分数变成行动）

评分不是终点，而是分流的开关：

| 等级 | 下一步（按顺序） | 时间 |
|---|---|---|
| **A** | ① 官网深挖采购决策人 → ② 定制开发信 → ③ 加 WhatsApp/Zalo → ④ 手动发送 | 当天 |
| **B** | ① 官网深挖采购决策人（与 A 级同等深挖）→ ② 补全联系方式 + WhatsApp/Zalo 双渠道必查 → ③ 定制/批量开发信 → ④ 跟进 | 当天深挖，2-3 天内触达 |
| **C** | 归档，标记"低优先"，待数据源更新后再评估 | 暂缓 |

> 🔴 **B 级深挖等同 A 级**：B 级客户（18-27 分）同样执行官网深挖 + 决策人实名挖掘 + WhatsApp/Zalo 双渠道必查 + 完整联系方式补齐，并在 HTML 看板全字段展示。B 级占线索池大头，补一个决策人或 WhatsApp 往往就能升 A 级，绝不因"是 B 级"就降低深挖标准。C 级（<18 分，含同行/信息不足）才降级为仅归档。

## 六、评分校准（越用越准的关键）

评分体系不是一成不变的，要**用真实反馈校准**：

1. **每月复盘**：统计「A 级的回复率、B 级转化率」，如果 B 级转化率反超 A 级，说明某个维度权重设置错了，需要调整。
2. **记录"误判"**：把"评分高但没回复"和"评分低却成交"的案例记下来，反推是哪一维判断失误。
3. **迭代权重**：例如发现"决策人触达"比"需求强度"更能预测成交，就提高它的权重。
4. **沉淀正负样本**：在本地线索池里加一列 `outcome`（成交/回复/无响应），累积 50+ 条后，评分会越来越准。

> 一句话：**评分是"假设"，成交是"真相"；用真相不断修正假设。**
