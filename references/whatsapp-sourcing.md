# WhatsApp 号码获取 SOP

> 目标：把「WhatsApp 只有 9/198」变成可复制的产能。**号码只能从客户自己公开的地方取**，
> 不接受买库、不接受撞号、不接受机器人群加——那是封号最快的方式，也会毁掉发信域名信誉。

## 零、先认清现实（截至 2026-11 池子实况）

| 指标 | 数量 | 说明 |
|---|---|---|
| 池内总客户 | 198 | 美国 139 / 越南 54 / 土耳其 5 |
| `WhatsApp` 列可用 | 9 | 4.5%，几乎等于没有 |
| `电话` 列可用 | 154 | 这是最大的待挖掘资产 |
| 其中**号段判定为手机** | 15 | 全在越南（越南 53 个电话里 38 个是 024/028 固话） |
| 有官网 | 155 | 可抓 wa.me |

结论：**号段推断能立刻多出 15 个，官网实抓能再挖一批，剩下的大头要靠渠道覆盖（见第二、三节）。**

## 一、置信度分级（写库前必须分清）

| 级别 | 来源 | 能不能直接发 |
|---|---|---|
| **高** | 官网页脚/联系页有 `wa.me/<号>`、`api.whatsapp.com/send?phone=`、"WhatsApp" 按钮 | 可以，这是客户主动公开的 |
| **中** | 官网 `tel:` 是手机号段 / 池内电话是手机号段 | 先点 `wa.me` 链接验一次再发 |
| **低** | 第三方平台、社媒简介里拼出来的号 | 必须人工核实归属，否则不发 |

**验证动作（10 秒）**：浏览器打开 `https://wa.me/84902701022`
- 出现聊天窗 + 头像/公司名 → 号码有效且开通了 WhatsApp
- 提示 "phone number shared via url is invalid" → 号码不存在，别写库
- 打开是你自己的聊天窗（没头像）→ 大概率未注册

## 二、六条找号渠道（按性价比排序）

### 1. 官网联系页（命中率最高，最干净）
除首页外必看这几条路径，越南/土耳其站常把 Zalo 和 WhatsApp 图标放在页脚：

```
/contact  /contact-us  /lien-he  /lienhe  /gioi-thieu  /ve-chung-toi
/iletisim  /kontakt  /contato  /contacto  /hubungi-kami  /about  /about-us
```

> 工具 `tools/find_whatsapp.py --crawl` 已自动追这些页面（含越南语/土耳其语路径变体），
> 并把 `hugedomains/sedo/godaddy` 停放页判为「域名失效」，顺手清理坏线索。

### 2. 谷歌搜索语法（人工 3 分钟能补一批）
```
"公司名" wa.me
"公司名" "whatsapp" +84
site:wa.me "<行业词> <城市>"          ← 直接捞公开挂 wa.me 的商家
"公司名" "+84" "09"                  ← 手机号常出现在报价单/目录页
"公司名" site:facebook.com           ← 主页的 WhatsApp 按钮
```

### 3. Facebook / Instagram 商业主页（越南、土耳其、印尼最有效）
商家主页的「发消息」按钮背后常是 WhatsApp Business 号；Bio 里也常直接写 `09xx xxx xxx`。
取号后必须和公司名核对，不能凭头像认。

### 4. 谷歌地图商家资料
`maps_scrape.py` 抓到的商家详情页里，部分市场的 `phone` 字段就是手机号；
按国家规则过一遍 `mobile_verdict()` 即可判定，无需再抓官网。

### 5. 行业目录 / 展会名录 / B2B 页
越南黄页（trangvangvietnam）、土耳其（turkiye.com.tr）、各国塑料协会会员名录。
**只取名录里企业自己填的手机号**，不取平台代发的转接号。

### 6. 老客户回捞（零成本，最容易被忽略）
已发过邮件、有回复的客户，回信签名或邮件头里的手机号，直接转 WhatsApp。
`客户跟进表.xlsx` 里 `已回复` 的记录优先过一遍。

## 三、各市场 WhatsApp 渗透率 → 决定先打谁

| 渗透率 | 市场 | 打法 |
|---|---|---|
| **极高**（B2B 主用 WhatsApp） | 印尼、印度、巴西、墨西哥、土耳其、尼日利亚、巴基斯坦、中东 | WhatsApp 作**主通道**，邮件为辅 |
| **高** | 西班牙、意大利、波兰、俄罗斯、泰国、马来西亚、哥伦比亚 | WhatsApp 与邮件并行 |
| **中（本土 IM 更强）** | **越南（Zalo 主导）** | 主通道是 **Zalo**，WhatsApp 只作补充 |
| **中** | 德国、法国、荷兰、英国 | 邮件为主，WhatsApp 作补充 |
| **低**（B2B 基本不用） | **美国、加拿大、日本、韩国** | 别在 WhatsApp 上耗时间，邮件 + LinkedIn |

> 池子里 139 家是美国 → **这是 WhatsApp 只有 4.5% 的根本原因，不是数据没挖到**。
> 想提高 WhatsApp 命中率，市场就得往印尼/印度/巴西/土耳其/中东挪。

### 3.1 实测证据（2026-11-16，越南 52 个官网抓通 24 个）

| 官网footer/contact 页出现的渠道 | 家数 | 占比 |
|---|---|---|
| Facebook 主页 | 17 | 71% |
| **Zalo** | **12** | **50%** |
| **WhatsApp** | **4** | **17%** |

结论：**越南 B2B 的聊天入口是 Zalo，不是 WhatsApp。** 想在越南拿 WhatsApp，性价比很低；
该市场应把 `Zalo` 列当主通道，WhatsApp 只作"客户自己留了才发"的补充。
美国同理——官网挂 wa.me 的极少（155 个站全抓，仅 3 家），B2B 靠邮件。

## 四、工具用法

```bash
# 1) 离线号段推断（秒出，不联网，先看手里有什么）
python tools/find_whatsapp.py --infer

# 2) 抓官网找 wa.me（需联网/代理；--market 可限定市场）
python tools/find_whatsapp.py --crawl --market 越南 --threads 8
python tools/find_whatsapp.py --crawl --grade A          # 只抓 A 级
python tools/find_whatsapp.py --crawl --limit 20 --shallow  # 试跑

# 3) 把「高置信」写回线索池（自动备份，只填空不覆盖）
python tools/find_whatsapp.py --crawl --commit
```

```bash
# 4) 把候选渲染成「点开即验」的清单页（含 wa.me 直链，手机/电脑都能点）
python tools/render_wa_worklist.py    # → reports/whatsapp-candidates.html
```

产出 `leads/_whatsapp_candidates.csv`：编号/公司名/国家/等级/官网/匹配来源/号码/证据/置信度/wa链接/备注。
**中置信不进库**，先点链接验，验过的再手工填进 `WhatsApp` 列或跟进表。
同一次抓取还会把「域名停放/已过期」的客户单独写到 `leads/_site_dead.csv`（这类线索官网已废，需重新核实）。

> **验证为什么必须人工点**：`wa.me/<号>` 页面在代理白名单外，脚本抓不到；
> 而且反爬会直接失败。点开看头像/公司名是 3 秒的事，是目前唯一可靠的判断方式。

> **抓取覆盖率的天花板**：155 个官网里约 40% 是 Cloudflare/WAF（返回 403），
> 纯 HTTP 抓不到；这类站点要用 `browser-deep-dive.md` 里的浏览器通道（用户自己的 Chrome）才看得见。
> 所以「抓了一轮没挖到」不等于「客户没有」，只等于「静态抓取看不见」。

## 五、写到对外素材里怎么用

- 有号且已验证 → 卡片显示「打开 WhatsApp 聊天」直链，两句钩子可直接粘。
- 有号未验证 → 标 `⚠️待验证`，别写进自动发送序列。
- 无号 → 显示「—」，**不要编号码**，不要用猜的号段。
- 一次只发一条，隔 2-3 天再追；同一号码累计 3 条无回应即停（防举报封号）。

## 六、红线

1. **不买号、不用群加工具、不批量导入通讯录** —— WhatsApp 封号主要就是因为这个。
2. **不发未经核实的号码**；号码归属对不上公司的一律不发。
3. **不在美国/日本客户身上堆 WhatsApp**，那是无效投入。
4. 号码写进池子必须带来源（哪一页、什么证据），做不到就留在候选表里等人核。
