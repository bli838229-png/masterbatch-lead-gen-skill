# A/B 级客户深挖与情报分析（官网研究 Agent 进阶）

本文档是「官网深挖」环节的进阶方法论，目标是把 **A 级和 B 级客户从"公司线索"升级为"可直接触达的决策人情报"**，并产出**可打开浏览的 HTML 详细资料分析界面**。

> 🔴 **深挖范围铁律（必读）**：**A 级和 B 级客户享受完全同等的深挖待遇**。不是"只深挖 A 级、B 级随便应付"，而是——凡是评分达到 A 级（≥28 分）或 B 级（18-27 分）的客户，都要**逐个执行官网深挖、决策人实名挖掘、WhatsApp/Zalo 双渠道必查、完整联系方式补齐**，并在 HTML 看板里**全字段展示**。C 级客户（<18 分，含同行/信息不足）才降级为"仅归档、不深挖"。理由：B 级客户占了线索池的大头，往往藏着大量"补一个 WhatsApp/决策人就能升 A 级"的潜力客户，只深挖 A 级会漏掉大半可成交机会。

---

## 一、深挖目标（把线索变"能联系的人"）

对每个 **A 级和 B 级**客户，尽最大努力补齐以下字段：

| 字段 | 优先级 | 说明 |
|---|---|---|
| 决策人姓名 + 职位 | ⭐⭐⭐ | 采购/总经理/销售负责人，可直接用于开发信称呼和 LinkedIn 搜索 |
| 官方邮箱（多邮箱更佳） | ⭐⭐⭐ | info@ / sales@ / 个人邮箱 |
| 电话 / WhatsApp / Zalo | ⭐⭐⭐ | 东南亚市场 Zalo 响应最快 |
| 认证（ISO/FDA/IATF 等） | ⭐⭐ | 判断高端定位与切入产品 |
| 出口市场 / 客户名单 | ⭐⭐ | 判断体量与需求 |
| 使用树脂清单 | ⭐⭐ | 精准匹配色母粒产品 |
| 规模（注塑机数/员工/产能） | ⭐ | 辅助评分 |

## 二、社交主阵地按市场切换（WhatsApp / Zalo / KakaoTalk / LINE）

**不同市场的社交主阵地完全不同，深挖时必须按市场切换目标**——否则会挖错渠道、白费力气：

| 市场 | 社交主阵地 | 深挖重点 |
|---|---|---|
| **美/英/澳/加** | **LinkedIn + 邮件**（WhatsApp 次之） | 决策人在 LinkedIn；邮件是主力，WhatsApp 普及度一般 |
| **德/法/意/西 + 拉美** | **WhatsApp + LinkedIn** | 南欧 WhatsApp 极普及，响应最快 |
| **越南（+ 东南亚大部）** | **Zalo**（覆盖远高于 WhatsApp） | Zalo 是第一优先，很多客户"有 Zalo 无 WhatsApp" |
| **韩国** | **KakaoTalk** | 韩国商务沟通主阵地，WhatsApp 几乎不用 |
| **日本** | **LINE + 邮件** | ⚠️ **日本不用 WhatsApp**，硬挖 WhatsApp 号等于白做；日企官网多无邮箱，走「お問い合わせ」表单 |
| **泰国** | **LINE**（第一）+ WhatsApp | LINE 是泰国国民级应用 |
| **中东（沙特/阿联酋/埃及）** | **WhatsApp** | 响应最快，英语可通行 |
| **巴西/葡萄牙语区** | **WhatsApp** | 渗透率极高 |

> 🔴 **必做项（铁律）**：按市场把「主社交渠道」和「次渠道」**都要查、都要在客户卡片里单独成行展示**，绝不能只盯一个漏掉另一个。
> - **越南市场**：查 Zalo（主）+ WhatsApp（次），Zalo 覆盖率远高于 WhatsApp，只查 WhatsApp 会漏掉大量可触达客户。
> - **欧美市场**：查 WhatsApp（主）+ LinkedIn（次），**美国等市场不用 Zalo，Zalo 列如实填「明确无—」**，不要凭空编号码。
> - **日本市场**：查 LINE（主）+ 邮件（次），**WhatsApp/Zalo 列如实填「该市场不使用—」**，不要为了「填满」而编一个国家代码。
> - **韩国市场**：查 KakaoTalk（主）+ 邮件（次），WhatsApp 同样填「该市场不使用—」。

**社交号三态标注标准（证据等级，三渠道通用）**：

1. **明确绑定（✅）**：官网/目录/主页明确标注 `(Zalo)` / `(WhatsApp)` / `wa.me/xxx` / `zalo.me/xxx` → 直接采信，绿色高亮。
2. **待验证（⚠️）**：只有手机号或 `Hotline`，未标注绑定哪个 App → 标注"可尝试用该手机号加 WhatsApp/Zalo 验证"，**不臆测为已绑定**。
3. **明确无（—）**：明确写了"仅电话/邮箱"、或该市场不使用该 App（如美国不用 Zalo） → 标"暂无"。

> ⚠️ **质量红线（当前最痛的问题）**：美国市场 81 家客户的 WhatsApp 全是「待验证⚠️」，**没有一个「明确绑定✅」**。这意味着触达前必须逐个用号码在 WhatsApp 里搜一遍确认。**深挖阶段如果能从官网/目录确证绑定，就要标 ✅；确证不了就老实标 ⚠️，绝不能为了好看把 ⚠️ 改成 ✅。**

**挖 WhatsApp/Zalo 的 4 个关键渠道**：

1. **官网页脚/联系页**：很多越南企业会把 `Hotline/Zalo: +84 xxx` 写进官网页脚或博客文章结尾（如某越南企业的 `Hotline/Zalo: +84 123 456 789`）。
2. **LinkedIn 帖子**：企业发布展会/招商帖时，常附上联系人的 WhatsApp（如 Tan Phu 在 LinkedIn 帖子公开了 4 个 WhatsApp：副总 + 出口经理 + 2 个销售）。
3. **B2B 目录站**：Yellow Pages、eriksen 等目录常标注 `Mobiphone`（手机号 = 可加 WhatsApp/Zalo），并给出联系人实名和职位（如某企业的销售经理 Mr. Example +84 123 456 789）。
4. **官方 Zalo 账号**：越南企业普遍有 Zalo 官方号（`zalo.me/xxx` 或品牌名搜索），比个人 WhatsApp 更容易找到。

**经验规律**：
- 手机号 `+84 9xx` 开头的基本都能加 Zalo（越南 Zalo 覆盖率极高），`+84` 手机号也可尝试 WhatsApp。
- **越南市场 Zalo 优先于 WhatsApp**：黄页/官网标 `(Zalo)` 或 `(ZALO)` 表示该号已绑 Zalo；WhatsApp 反而是少数。深挖时「查 Zalo」是第一优先动作。
- 目录站的"Contact name + Mobiphone"字段是**挖决策人 WhatsApp/Zalo 的富矿**，官网抓不到时优先转目录站。

## 三、深挖的 4 个数据源（按优先级）

### 1. 官网首页 + 联系页（第一优先）
- 先抓官网首页提取业务、产品线、认证、出口市场。
- 再抓 `/contact`、`/lien-he`（越南语）、`/about-us` 页提取联系方式。
- **提示词模板**：
  ```
  这是【公司】的官网。请提取：1) 主营业务和产品线 2) 所有公开邮箱、电话、地址
  3) 采购/销售/总经理等负责人姓名和职位 4) 公司规模、认证、出口市场 5) 联系页完整信息。
  逐条列出，不要遗漏任何邮箱和电话。
  ```

### 2. 本地 B2B 目录站（决策人富矿）
越南场景最有效的目录站：
- **Yellow Pages Vietnam**（`yellowpages.com.vn`）—— 常含"Verified"认证、法人代表姓名、个人邮箱、手机号。
- **Distrilist**（`distrilist.eu`）—— 越南塑料包装企业名录，含邮箱电话。
- **manufacturing.com.vn / sourceready.com** —— 制造业供应商名录。

> ⚠️ **关键经验**：越南企业官网普遍不公开个人邮箱（隐私习惯），但目录站常能挖到 **法人/总经理实名 + 个人邮箱/手机号**（如 Vietdragon 的 Tran Quang Quy）。所以官网抓不到决策人时，**一定要转目录站**。

### 3. 搜索引擎补充（官网失效时）
官网 fetch 失败（SSL 异常/反爬）时，用 `公司名 + contact email` 搜索，从目录站、新闻稿提取联系方式。

### 4. 社交媒体（LinkedIn / Zalo / Facebook）

- LinkedIn：手动搜「公司名 + Purchasing/Procurement/Sourcing」岗位（仅辅助，不自动化）。欧美市场决策人主力在 LinkedIn，触达优先 LinkedIn + WhatsApp。
- Zalo/Facebook：越南企业常公开 Zalo 官方号，加好友响应快。

> ✅ **已验证有效的 Facebook 深挖经验（优先采用）**：越南企业官网的 footer / 联系页**几乎都挂着 `facebook.com/xxx` 和 `zalo.me/xxx` 链接**。深挖社交号时，**第一步先解析官网 `<a href>` 里的 facebook.com / zalo.me / wa.me 链接**，比 Google 搜索、Facebook 站内搜索都精准（官方主页、零同名噪声）。只有官网没挂链接时，才退而用 `site:facebook.com "公司本地语言名"` 去 Google 定位官方主页。完整关键词与搜索语法见 [`multilingual-keywords.md`](multilingual-keywords.md)「五、社交媒体深挖关键词」。

## 四、决策人挖掘的合规红线

1. **只用公开信息**：官网、目录站、公开新闻稿公开的联系方式；不购买/爬取非公开数据。
2. **个人隐私克制**：只收集与商务相关的公开决策人信息，不收集无关私人数据。
3. **LinkedIn 仅辅助**：AI 整理"该联系谁 + 开场白"，手动点发送；绝不自动化加好友/私信。
4. **事实可溯源**：每条决策人信息标注来源（官网/目录站/新闻），无法核实的写「待核实」。

## 五、产出：HTML 详细资料分析界面

深挖完成后，产出**两类 HTML 看板**，便于直接浏览和分享：

### 看板 A：评分明细看板（全量 A/B/C）

- **必须覆盖 A/B/C 全部客户**（不是只放 A 级），让用户看清"全量排名"。
- 每家客户卡片必含：
  - **排名徽标**（#1、#2…，按总分降序，同分并列）
  - **总分 + 等级**（大字显示 `xx / 35` + A/B/C 徽标）
  - **7 维分数条**（每维 0-5 分，用条形可视化，高分绿色、中分橙色、低分浅色）
  - **逐维评分理由**（每个维度下面挂一句理由，指向具体证据）
  - **负分项 / 一票否决**（如有，红色高亮标注）
  - **一句话总评**
- 顶部统计卡片：客户总数 / A 级数 / B 级数 / C 级数。
- 筛选标签：全部 / A 级 / B 级 / C 级，一键切换分批处理。

> **评分透明的意义**：用户能一眼看出"这家凭什么排第 3、为什么总分 29、弱在哪一项"，而不是对着一个黑箱字母发懵。完整评分规范见 [`lead-scoring.md`](lead-scoring.md)「评分透明化」章节。

### 看板 B：WhatsApp 联系清单（A/B 级全量，非仅 A 级）

- 顶部：统计卡片（客户数 / 行业数 / 决策人数 / 联系方式数）
- 搜索框 + 行业筛选标签（可按"注塑/线缆/包装/精密"筛选，另加"📱 有WhatsApp/Zalo"快捷筛选）
- 客户卡片：公司名 + 行业徽章 + 城市 + 官网/邮箱/电话 + 决策人 + 树脂标签 + 规模/认证 + 推荐产品 + 切入建议
- **联系方式区块必须把「WhatsApp」和「Zalo」拆成两行单独展示**（不是合并成一行），每行按「明确绑定✅ / 待验证⚠️ / 明确无—」三态标注
- **每张卡片附 WhatsApp 开场白区块**（越南语 + 英语双语，一键复制按钮），让用户"复制即发"
- 底部：数据来源与生成时间声明

**切入建议（每客户必写）**：一句话点出"为什么这家的什么痛点对应你的什么产品"，例如：
> "服务 Schneider/Samsung 巨头，医疗级 ISO 13485 + IATF 16949，医疗级配色母粒价值极高。"

**WhatsApp 开场白（每客户必写，放卡片内）**：
- **严格两句**：① 我是谁 + 我做什么（针对他的工艺） ② 一句痛点判断 + 一个几乎零成本的提问。
- **英语为主 + 当地语言问候语**（越南语用 anh/chị + 名字），有实名决策人的直接称呼其名。
- 写作方法论与真实范例见 [`outreach-templates.md`](outreach-templates.md) 2.4.1 与第七章。
- 卡片里加「📋 复制 WhatsApp 英文」按钮，点击即复制到剪贴板。

## 六、深挖的完整执行序列（可直接套用）

```
① 从线索池筛出 A 级 + B 级客户清单（按评分降序，B 级与 A 级同等深挖）
② 对每家并行抓官网（首页 + 联系页）
③ 官网无决策人 → 转目录站搜索「公司名 + contact / email」
④ 官网失效 → 用搜索引擎补抓
⑤ 汇总每条线索的决策人/邮箱/认证/出口市场
⑥ 写"切入建议"（痛点 → 对应产品）
⑦ 为每家写 WhatsApp 开场白（本地语言+英语，点名决策人）
⑧ 整合成 HTML 详细资料分析界面（A/B 级全量，含开场白 + 一键复制按钮）
⑨ 人工复核 + 标注来源，更新线索池 CSV
```

## 七、常见坑与应对

| 坑 | 应对 |
|---|---|
| 官网 fetch 失败（SSL/反爬） | 转目录站/搜索引擎补充 |
| 越南企业官网不公开个人邮箱 | 目录站挖法人/总经理实名 + 个人邮箱 |
| 官网是纯静态无联系方式 | 抓 `/contact` 子页，或目录站 |
| 多个同名公司混淆 | 用税号/地址/城市交叉核验 |
| 抓到竞品（色母粒同行） | 正确降级为 C 级"可合作/竞品"，不作客户 |
