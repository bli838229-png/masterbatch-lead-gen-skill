# 分层获客关键词库（按 A/B/C 层级 + 双渠道）

> 本文档是 `multilingual-keywords.md` 的**战略升级**：不再"一把关键词扫天下"，而是**先按客户价值预判 A/B/C 层级，再用不同的关键词组合去精准捞对应层级的客户**。同时打通**谷歌地图、谷歌浏览器**两条获客渠道的搜索规则。

---

## 一、核心理念：为什么按 A/B/C 分层配关键词？

搜索的终点不是"搜到公司"，而是"搜到**值得花力气**的公司"。A/B/C 三级客户的价值、决策链、触达难度完全不同，所以：

| 层级 | 客户画像 | 关键词的"瞄准方向" | 搜索目标 |
|---|---|---|---|
| **A 级** | 工程塑料注塑/家电电子外壳/汽车内饰/线缆料，需阻燃+定制配色，决策人可触达 | 高价值行业词 + 认证词 + 决策人词 | 直接锁定"说了算的人"和"现在就要的厂" |
| **B 级** | 通用塑料加工/包装/日用品，有配色需求但价格敏感或信息不全 | 行业词 + 规模词 + 联系方式词 | 先捞出大批量候选，再深挖补信息升 A |
| **C 级** | 一次性工程/纯贸易/信息不足/疑似同行 | 排除词 + 负向信号词 | 快速筛掉，节省火力 |

> **一句话**：A 级用"精准狙击"关键词，B 级用"广撒网"关键词，C 级用"排雷"关键词。

---

## 二、A 级关键词（精准狙击 · 高价值刚需客户）

> **目标**：找到"必须用阻燃母粒/定制色母粒 + 有明确采购决策人"的优质厂。命中即重点深挖。

### 2.1 高价值行业词（产品匹配度 5 分的行业）

| 行业 | 英语关键词 | 判断信号 |
|---|---|---|
| 工程塑料注塑 | `engineering plastic injection molding` `POM PA66 PC ABS injection molder` | 材料明确，着色门槛高 |
| 家电/电子外壳 | `UL94 V0 flame retardant housing` `electrical enclosure molder` `appliance plastic parts` | 阻燃是刚需 |
| 汽车内饰/外饰 | `automotive interior trim injection molding` `automotive plastic parts supplier` | 配色要求高、订单稳定 |
| 线缆/电缆料 | `wire and cable compound manufacturer` `flame retardant cable jacket compound` | 阻燃母粒用量大 |
| 医药/食品包装 | `medical device injection molding ISO 13485` `food grade plastic packaging` | 认证壁垒高、粘性强 |

### 2.2 认证/资质词（筛出"有准入门槛"的正规厂）

```
ISO 9001 "injection molding"
IATF 16949 "automotive plastic"
ISO 13485 "medical plastic"
UL listed "plastic enclosure"
FDA approved "food packaging"
```

### 2.3 A 级专属搜索组合模板（直接套用）

```
# 找工程塑料注塑厂（英语市场）
"injection molding" "engineering plastic" "UL94" -recycling -machine

# 找线缆阻燃料厂
"cable compound" "flame retardant" manufacturer "United States"

# 找家电阻燃外壳厂（带决策人）
"appliance housing" molder "purchasing" OR "procurement"

# 德国市场（德语）
"Kunststoff" "Spritzguss" "flammhemmend" "Einkauf"
```

## 三、B 级关键词（广撒网 · 批量候选池）

> **目标**：用行业词 + 规模词 + 联系方式词，一次性捞出大量塑料加工厂，为"A 级补位"储备候选。命中后深挖补信息（挖到决策人/WhatsApp 即可升 A）。

### 3.1 通用行业词（覆盖注塑/挤出/吹塑/管材/包装）

| 用途 | 英语关键词 |
|---|---|
| 注塑 | `injection molding company` `custom injection molder` `plastic injection molding` |
| 挤出 | `plastic extrusion` `profile extrusion` `pipe extrusion` `film extrusion` |
| 吹塑 | `blow molding` `plastic bottle manufacturer` |
| 管材/接头 | `plastic pipe fittings` `PVC pipe manufacturer` `HDPE pipe` |
| 包装 | `plastic packaging manufacturer` `flexible packaging` |
| 日用品 | `plastic household products` `plastic housewares manufacturer` |

### 3.2 规模定位词（锁定"中等规模、匹配你产能"的厂）

```
"plastic" "injection molding" "employees" 50..500
"plastic manufacturer" "factory" "since 19" OR "since 20"
"plastic processing" "manufacturing facility"
```

### 3.3 B 级搜索组合模板（广撒网）

```
# 美国中西部注塑厂批量
"injection molding" company "Ohio" OR "Michigan" OR "Indiana" -machinery -supplier

# 挤出厂批量
"plastic extrusion" manufacturer "contact" -recycling

# 吹塑/包装厂批量
"blow molding" OR "plastic packaging" "contact us" "Made in USA"
```

## 四、C 级关键词（排雷 · 快速筛掉低价值/干扰项）

> **目标**：用排除词 + 负向信号词，把"同行、设备商、回收商、一次性工程、贸易商"提前挡在池外，节省评分和深挖的火力。

### 4.1 排除词（搜的时候直接加 `-` 号）

| 要排除的 | 排除词 |
|---|---|
| 色母粒同行/供应商 | `-masterbatch supplier` `-color concentrate` `-colorant manufacturer` |
| 设备/机械商 | `-injection molding machine` `-machinery` `-equipment` |
| 回收/再生料 | `-recycling` `-recycled` `-regrind` |
| 贸易/分销商 | `-distributor` `-trader` `-trading` `-wholesale` |
| 树脂原料厂 | `-resin supplier` `-polymer manufacturer` |

### 4.2 负向信号词（识别"低价值/一次性"客户）

```
"one-time project" / "prototype only" / "prototyping service"
"plastic parts" "prototype" (3D打印打样型，非量产)
"plastic trading" / "export agent" / "sourcing agent"
```

### 4.3 C 级搜索组合模板（排雷）

```
# 搜注塑但排除同行/设备/回收/贸易
"injection molding" -masterbatch -machine -recycling -distributor -trading

# 识别纯打样
"plastic parts" "prototype" -production -manufacturing
```

## 五、渠道①：谷歌地图（Google Maps）搜索规则

> 谷歌地图是**发现本地真实实体厂**的第一优先渠道（信息硬、含电话+地址+坐标）。地图列表页不给官网，官网需靠后续搜索/深挖补。
>
> ⚡ **不要手工拼关键词**：用 `python tools/kwgen.py --country <市场> --tier all --cities 3 --cmd` 自动生成（按国家出本地语言词 + 城市轮换 + 行业轮转），完整流水线见 `maps-keyword-system.md`。下文是它背后的规则说明。

### 5.1 地图分片搜索规则（核心）

地图 feed 是虚拟列表、滚动不灵，所以用**「多关键词 × 多城市」分片搜索**替代滚动：

```
python tools/maps_scrape.py "<地区>" "<关键词1>,<关键词2>,<关键词3>,<关键词4>"
```

- **关键词 4-6 组**，每组含**城市名**，结果差异更大
- 每个查询抓 10-20 家，合并去重凑满 30+

### 5.2 地图关键词按 A/B/C 分层

| 层级 | 地图关键词示例（美国） |
|---|---|
| **A 级** | `engineering plastic injection molding` `UL94 flame retardant molding` `automotive plastic parts` |
| **B 级** | `injection molding` `plastic extrusion` `blow molding` `plastic packaging` |
| **C 级排雷** | 加城市 + 避开 `plastic recycling` `machine shop` |

### 5.3 地图搜索组合模板

```bash
# 美国俄亥俄州（多关键词分片）
python tools/maps_scrape.py "Ohio" "injection molding Cleveland,plastic extrusion Columbus,blow molding Cincinnati,plastic packaging Akron"

# 德国巴伐利亚（德语关键词）
python tools/maps_scrape.py "Bayern" "Kunststoff Spritzguss München,Kunststoffverarbeitung Nürnberg,Masterbatch Augsburg"

# 韩国京畿道（韩语关键词）
python tools/maps_scrape.py "Gyeonggi" "사출 성형,플라스틱 압출,난연 마스터배치"
```

### 5.4 地图抓取后的必做动作

1. 拿到 `name/tel/addr` → 用**搜索补官网**（`"公司名" official website`）
2. 官网品牌名匹配打分（防张冠李戴）→ 打开官网深挖邮箱/社交/决策人
3. 完整流程见 `browser-deep-dive.md`

## 六、渠道②：谷歌浏览器（Google Chrome）搜索规则

> 谷歌浏览器是**深挖的第一优先工具**：开真实 Chrome（走系统代理，Google 才通），实时抓官网/联系页/决策人/footer 社交链接。搜索语法与"普通 Google 搜索"复用 `multilingual-keywords.md` 第一章的高级语法。

### 6.1 浏览器深挖的搜索时机（按层级）

| 层级 | 浏览器深挖动作 |
|---|---|
| **A 级** | 必深挖：打开官网 → 联系页抓邮箱/电话 → footer 抓社交 → About/Team 抓决策人实名 |
| **B 级** | 与 A 级同等深挖（补一个决策人/WhatsApp 就可能升 A） |
| **C 级** | 仅归档，不深挖 |

### 6.2 浏览器内 Google 搜索语法（配合分层）

```
# 找 A 级决策人（浏览器内 Google 搜）
"公司名" "procurement" OR "purchasing" OR "supply chain"
"公司名" "general manager" OR "managing director"

# 定位社交主页（浏览器内 Google 搜）
site:facebook.com "公司本地语言名"
site:linkedin.com/company/ "公司名"
site:linkedin.com/company/ "公司名" plastic

# 找公司简介 PDF（含电话/邮箱）
filetype:pdf "公司名" "company profile"
filetype:pdf "catalog" "masterbatch" "color"
```

### 6.3 浏览器深挖执行序列（每家 A/B 级）

```
① 打开官网首页 → 抓 title + body（业务/产品/认证/规模）
② 解析 footer 社交链接：facebook.com / zalo.me / wa.me / linkedin.com
③ 打开联系页（/contact /contact-us /about /team；越南加 /lien-he）→ 抓邮箱/电话
④ 提取决策人：body 搜 procurement / purchasing / sales / general manager / CEO / owner
⑤ 官网无决策人 → 搜索兜底：site:linkedin.com/company/ "公司名"
⑥ 每条信息标来源，抓不到写「待核实⚠️」
```

> 完整浏览器命令、端口探测、降级规则见 `browser-deep-dive.md`。

## 八、快速上手指南（每天怎么用）

1. **定市场** → 读 `market-plan.csv` 切换规则，确定国家+语言。
2. **A 级狙击** → 先用 A 级关键词（2.1-2.3）+ 地图 A 级词，精准捞高价值刚需厂。
3. **B 级广撒网** → 用 B 级关键词（3.1-3.3）+ 地图 B 级词，批量补齐候选池。
4. **C 级排雷** → 搜的时候始终带排除词（4.1），把同行/设备/回收/贸易挡在池外。
5. **评分入库** → 按 `lead-scoring.md` 7 维打分，A/B/C 分级，深挖 A/B 级。

> **铁律不变**：每天 30 家真实数据、发送永远人工、信息标来源、数据只存本地。
